## Getting Started

### Step 1: Sign Up as a Teacher
1. Visit the TechXplora homepage
2. Click "Start as Student or Teacher"
3. Select "I'm a Teacher"
4. Complete the registration form with your details
5. Verify your email address

### Step 2: Complete Your Profile
1. Navigate to **Dashboard → Profile → Edit Profile**
2. Upload a profile photo
3. Fill in your personal information:
   - Name and contact details
   - Country, State, and LGA
   - Date of birth
4. Click "Save Changes"

## Creating Your First Group

Groups help you organize students by class, subject, or any category you prefer.

### Steps to Create a Group:
1. Go to **Dashboard → Groups**
2. Click "Create New Group"
3. Fill in the group details:
   - **Title**: Name your group (e.g., "Grade 5 Mathematics")
   - **Description**: Brief description of the group
4. Click "Create Group"
5. Note your **Group Code** - students will use this to join

### Sharing the Group Code:
- Share the group code with your students
- Students can join by entering the code in their dashboard
- You can view all group members in the group details page

## Creating Quizzes

### Understanding Quiz Modes
TechXplora offers three quiz modes:

1. **Learning Mode**: Students can retake quizzes to improve
2. **Practice Mode**: Timed practice with instant feedback
3. **Competition Mode**: One-time attempt, leaderboard enabled

### Step-by-Step Quiz Creation:

#### Step 1: Basic Information
1. Navigate to **Dashboard → Create Quiz**
2. Fill in quiz details:
   - **Title**: Give your quiz a clear name
   - **Description**: Explain what the quiz covers
   - **Quiz Mode**: Select the appropriate mode
   - **Group**: Choose which group can access this quiz
   - **Class**: Select the class level

#### Step 2: Schedule & Settings
- **Start Date & Time**: When the quiz becomes available
- **End Date & Time**: Quiz deadline
- **Duration**: Time limit per quiz (in minutes)
- **Age Range**: Optional age restrictions (min/max)

#### Step 3: Points Allocation
- **Total XP**: Points students can earn
- **Points per Question**: XP awarded for each correct answer
- Monitor "Points Left" to ensure you have enough XP

#### Step 4: Add Questions
You have three options:

**Option A: Manual Entry**
1. Click "Add Question Manually"
2. Enter question text
3. Add answer options (A, B, C, D)
4. Mark the correct answer
5. Repeat for all questions

**Option B: Excel Upload**
1. Download the Excel template
2. Fill in questions following the format:
   - Column A: Question text
   - Columns B-E: Answer options
   - Column F: Correct answer (A/B/C/D)
3. Upload the completed file

**Option C: AI Generation**
1. Click "Generate with AI"
2. Enter the topic or subject
3. Specify number of questions
4. Review and edit generated questions
5. Save to quiz

#### Step 5: Review & Publish
1. Preview all questions
2. Check quiz settings
3. Click "Create Quiz"
4. Share the quiz code with students

## Managing Students

### Viewing Student Progress
1. Go to **Dashboard → Groups**
2. Select a group to view members
3. Click on individual students to see:
   - Quiz attempts
   - Scores and XP earned
   - Time spent on quizzes

### Monitoring Quiz Results
1. Navigate to **Dashboard → Quiz Results**
2. Select a quiz to view:
   - Overall statistics
   - Individual student performance
   - Question-by-question analysis
   - Completion rates

### Leaderboard
- Access **Dashboard → Leaderboard** to see:
  - Top performers in your groups
  - XP rankings
  - Student engagement levels

## Best Practices

### Creating Effective Quizzes

**1. Clear Questions**
- Use simple, direct language
- Avoid ambiguous wording
- One concept per question

**2. Balanced Difficulty**
- Mix easy, medium, and hard questions
- Start with easier questions to build confidence
- Gradually increase difficulty

**3. Appropriate Timing**
- Allow 1-2 minutes per question
- Consider reading time for longer questions
- Test the quiz yourself first

**4. Fair Point Distribution**
- Allocate more points to harder questions
- Ensure total XP is reasonable
- Monitor your XP budget

### Engaging Students

**1. Regular Quizzes**
- Create weekly or bi-weekly quizzes
- Maintain consistent schedule
- Mix quiz modes for variety

**2. Timely Feedback**
- Review results promptly
- Provide constructive feedback
- Celebrate top performers

**3. Use Learning Mode**
- Allow retakes for learning
- Focus on improvement, not just scores
- Encourage practice

### Managing Your XP Budget

**Understanding XP:**
- You have a limited XP pool
- XP is allocated when creating quizzes
- XP returns when quiz ends
- Plan your quizzes accordingly

**Tips:**
- Don't create too many high-XP quizzes at once
- Stagger quiz end dates
- Monitor "Points Left" indicator
- Prioritize important assessments

## Troubleshooting

### Common Issues

**Students Can't Join Group:**
- Verify the group code is correct
- Check if group is active
- Ensure students are registered

**Quiz Not Appearing:**
- Check start date/time hasn't passed
- Verify group selection
- Confirm quiz is published

**Not Enough XP:**
- Wait for previous quizzes to end
- Reduce points per question
- Create shorter quizzes
